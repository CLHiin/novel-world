# 小說網站

## 開啟方式

網站使用 ES modules 與 `fetch` 讀取小說資料，請透過本機靜態伺服器開啟，不要直接以 `file://` 開啟。

在專案根目錄執行：

```powershell
python -m http.server 8000
```

再以瀏覽器開啟 `http://localhost:8000`。

## 目前功能

- 首頁依 `素材/web.json` 顯示小說書架。
- 新增小說、篇章、圖鑑資料與多段解鎖的格式，請參閱[小說資料新增指南](./小說資料新增指南.md)。
- 小說首頁提供章節、人物、世界觀與地圖入口。
- 桌面書架與圖鑑使用 16:9 畫布；窄螢幕改用原尺寸的直向畫布，避免把文字和圖片整頁做非整數縮小。章節閱讀一律切換為不旋轉的文字版面。
- 左上角麵包屑是唯一的逐層回溯方式；閱讀模式把麵包屑、選單及右下尺寸控制固定在閱讀視窗，麵包屑目的地都有明確導覽動作。
- 右下尺寸控制位於畫布內；閱讀模式固定於閱讀視窗。
- 小說首頁入口按鈕採緊湊、固定 padding 的網格；小／中／大只切換設定好的文字大小與每列數量，不會改變按鈕高度、padding 或區塊間距。首頁面板置中，並以對稱的捲軸預留空間平衡左右留白。
- 右側設定會逐項列出「大【】中【】小【】」數值。小說首頁（第一層）調整主副標題、大／小入口的字級與每列數量，不顯示搜尋欄；小說內列表（第二層）共用章節、人物、世界觀與地圖設定，可分別調整標題、副標題、搜尋欄、選項標題／說明字級及每列選項數。各區預覽會即時反映目前尺寸與欄數；設定保存在瀏覽器 `localStorage`。
- 設定頁可匯出／匯入 JSON 備份，包含外觀設定、各小說閱讀進度、完成章節、閱讀書籤、最後選擇的小說及介面大小。匯入前會先確認並驗證備份資料。
- 介面大小只套用各設定欄位的大／中／小字級和可調整的每列數量；按鈕 padding 與中央面板／閱讀框架尺寸不會隨尺寸切換。
- 右側選單的閱讀書籤是可累積的跨小說清單；閱讀任一章節可加入或移除書籤，清單可搜尋、刪除，並直接跳至不同小說／篇章／章節及保存的閱讀位置。已加入書籤的章節會隨閱讀同步目前進度。
- 小說首頁固定保留「小說篇章」與「繼續閱讀」兩個主要入口；沒有閱讀紀錄時「繼續閱讀」會維持原位並呈停用狀態，有紀錄才會跳到最後閱讀位置。
- 章節索引採「小說架構 → 篇章索引 → Markdown 章節」三層相對路徑。
- Markdown 正文在固定大小的閱讀框架內連續捲動；閱讀位置會保存，點擊「完成本章」才記錄章節完成。閱讀器在章節完成前後都持續顯示目前百分比，捲動時即時更新。
- 長正文只在閱讀框架內捲動，章節標題、操作列與版面大小控制維持固定位置。
- 完成章節後，閱讀操作會直接前往下一章或下一篇章的第一章；最後一章仍保留可回到的章節書籤，不會被送回篇章列表。
- 已完成的末章會保留最後閱讀位置；重新使用閱讀書籤可回看該章，不會因完成而遺失返回入口。
- 圖鑑列表和詳情使用固定外框；新增詳情或長文字只在面板內捲動，不會撐大中央面板。閱讀模式的麵包屑提供一致的水平捲軸樣式。
- 圖鑑摘要只顯示於列表選項；詳情不重複顯示摘要，若詳細內容開頭重複摘要則從正文移除。詳情面板插入所選項目下一列，再點同一項目可收合。
- 閱讀器在桌面將章節操作與進度維持同一列；窄螢幕時進度獨立一列、操作按鈕分成兩列配置，避免按鈕互相擠壓。
- 小說首頁、章節列表與圖鑑面板使用一致的金色細捲軸樣式；閱讀正文也有獨立捲軸。
- 窄螢幕直向畫布使用 100% 可用視窗，不旋轉或縮放 16:9 畫布；預設「中」尺寸下首頁面板約 94% 寬、80% 高，面板採 `border-box`，padding 計入既定寬高。
- 人物、世界觀與地圖支援名稱／標籤搜尋、摘要、詳細內容及跨類型連結。
- 人物肖像可留空並使用「？」預設頭像；地圖圖片可選填。
- 圖鑑肖像與地圖圖片可點擊或以鍵盤聚焦放大預覽，Escape、關閉按鈕或點擊遮罩可關閉。
- JSON 與 Markdown 透過瀏覽器重新驗證快取；`index.html` 與相依模組使用一致版本參數，更新模組時需一併更新版本值，避免使用舊版快取。
- 圖鑑資料可一開始公開或封鎖；封鎖內容可設定於指定章節完成後解鎖。
- 閱讀進度以章節內捲動位置（像素）保存；百分比在捲動時即時更新，位置資料則在短暫停止捲動後寫入。已加入書籤的章節也會同步最新位置與百分比；既有百分比格式進度仍可讀取並逐步轉為像素位置。閱讀進度、完成章節與跨小說閱讀書籤存在瀏覽器 `localStorage`，不會修改小說資料檔。
- 16:9 畫布以瀏覽器 `zoom` 縮放搭配旋轉，不再用 `transform: scale()` 縮放整張畫布，以減少手機模擬小尺寸時文字經合成縮放而發糊的情形。模擬裝置仍僅作版面參考。
- 小說首頁「繼續閱讀」有閱讀紀錄時會回到最後讀過的章節及捲動位置，即使該章已標記完成也不會跳到下一章；沒有紀錄時則停用該按鈕。
- 首頁新增原創小說世界「霧港拾信人」；《大潮以前》目前收錄四章，並含可搜尋、互相連結、依章節分段解鎖的人物、世界觀和地圖資料。

新安裝時各尺寸的主要字級預設如下；各項可以在設定頁獨立修改：

| 版面／設定項目 | 大 | 中 | 小 |
| --- | ---: | ---: | ---: |
| 首頁標題 | 42px | 38px | 34px |
| 首頁一般文字／卡片 | 22px | 20px | 18px |
| 小說世界標題／副標題 | 54px／22px | 48px／20px | 42px／18px |
| 小說大入口／小入口 | 28px／24px | 24px／20px | 20px／17px |
| 閱讀標題／正文 | 20px／26px | 18px／22px | 16px／18px |
| 閱讀輔助文字／操作按鈕 | 20px／20px | 18px／18px | 16px／16px |
| 首頁圖片每列數 | 2 | 3 | 4 |
| 小說大入口／小入口每列數 | 2／3 | 2／3 | 2／2 |

首頁、小說世界、小說入口、章節標題、閱讀正文、進度與操作按鈕的實際字級可在右側「設定」逐項調整；上述數值是新安裝的預設值。

## 程式模組

- `js/main.js`：啟動與連接全域按鈕。
- `js/app-state.js`：集中保存目前小說、篇章、導覽外的閱讀與圖鑑狀態。
- `js/navigation.js`：切換畫面與繪製麵包屑導覽。
- `js/data-store.js`：JSON、相對路徑、本機閱讀進度與跨小說書籤存取。
- `js/catalog.js`：書架、篇章／圖鑑列表、搜尋、跨小說書籤管理、資料詳情及連結。
- `js/reader.js`：Markdown 正文呈現、框架內捲動、閱讀進度、章節完成與章節書籤。
- `js/reading-presentation.js`：從首頁起套用並保存全站小／中／大尺寸。
- `js/settings.js`：字級與欄數設定、即時預覽，以及閱讀設定／紀錄的 JSON 匯入匯出。

## 小說資料位置

以「天賦權能」為例：

```text
素材/小說/天賦權能/
├─ 架構/web.json
├─ 劇情/聖地篇/
│  ├─ index.json
│  ├─ 001.md
│  └─ 002.md
├─ 人物/index.json
├─ 世界觀/index.json
└─ 地圖/index.json
```

「霧港拾信人」是獨立試讀資料，位於 `素材/小說/霧港拾信人/`；新增內容不會覆寫「天賦權能」的章節或設定。
試讀設定刻意包含長短不同的摘要、三名人物、不同長度的世界觀介紹，以及多個地圖條目；簡澄使用原創 SVG 肖像、霧港條目使用原創 SVG 地圖，阿沅則保留無肖像狀態以檢查預設頭像呈現。條目圖片路徑相對於 `架構/web.json`，可參照 `人物/index.json` 的 `portrait` 和 `地圖/index.json` 的 `image` 欄位。圖片可用點擊或鍵盤 Enter／空白鍵放大預覽。

### 定義篇章與章節

在小說的 `架構/web.json` 中定義篇章，索引路徑相對於該檔案：

```json
{
  "story": {
    "arcs": [
      {
        "id": "holy-land",
        "title": "聖地篇",
        "index": "../劇情/聖地篇/index.json"
      }
    ]
  }
}
```

每個篇章索引列出章節；章節正文路徑相對於篇章索引檔：

```json
{
  "id": "holy-land",
  "title": "聖地篇",
  "chapters": [
    {
      "id": "holy-land-001",
      "number": "001",
      "title": "抵達聖地",
      "file": "001.md"
    }
  ]
}
```

章節 `id` 請使用全小說唯一值。章節標題由篇章 `index.json` 的 `title` 欄位控制；Markdown 正文可直接使用一般段落、`##` 以下小標題、粗體與斜體。若正文第一行是 `# 標題`，閱讀器會將它視為文章主標題並省略，避免與固定標題列重複。長文在固定的閱讀區域內捲動，不會把操作列推離畫面。

### 定義人物、世界觀與地圖

各分類的 `index.json` 使用 `items` 陣列。下例是世界觀資料：

```json
{
  "items": [
    {
      "id": "magic",
      "name": "魔法",
      "tags": ["力量體系", "術式"],
      "summary": "此主題可先公開的簡介。",
      "initialStatus": "locked",
      "unlockAfter": ["holy-land-001"],
      "unlockHint": "完成第一章後解鎖。",
      "content": "解鎖後顯示的詳細內容。",
      "links": [
        {
          "type": "characters",
          "id": "character-id",
          "label": "相關人物"
        }
      ]
    }
  ]
}
```

- `initialStatus` 可設為 `open` 或 `locked`，省略時預設為 `open`。
- `unlockAfter` 填入章節索引中的章節 `id`；符合其中任一已完成章節後，資料即解鎖。
- 若詳細資料需要分段解鎖，可改用 `sections` 陣列；每段各自設定 `id`、`title`、`content` 與 `unlockAfter`。介面會列出篇章、章節及完成狀態，點選章節可直接前往閱讀。
- `sections[].unlockAfter` 可用章節 ID 字串；若 ID 可能重複，可用 `{ "arcId": "篇章 ID", "chapterId": "章節 ID" }` 指定篇章。

```json
{
  "sections": [
    {
      "id": "part-a",
      "title": "A",
      "content": "第一段設定。",
      "unlockAfter": ["chapter-003"]
    },
    {
      "id": "part-b",
      "title": "B",
      "content": "第二段設定。",
      "unlockAfter": [
        {
          "arcId": "main",
          "chapterId": "chapter-008"
        }
      ]
    }
  ]
}
```

- 人物項目可加 `portrait`；地圖項目可加 `image`。圖片路徑以小說的 `架構/web.json` 為相對基準，例如 `../人物/圖片/角色.png`。
- `links[].type` 使用 `characters`、`world` 或 `maps`；`links[].id` 指向該分類項目的 `id`。
- 人物、世界觀及地圖的項目都能使用 `tags`、`summary`、`content`、`links`。

解鎖僅是靜態網站的閱讀進度呈現，不是內容保密機制；資料檔本身仍可被讀取。清除瀏覽器本機網站資料會移除閱讀進度和解鎖狀態。
