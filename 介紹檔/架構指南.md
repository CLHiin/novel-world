# 專案架構

```text
小說網站/
├─ index.html
├─ css/
│  └─ style.css
├─ js/
│  ├─ main.js
│  ├─ lazy-loader.js
│  └─ viewport.js
├─ 素材/
│  ├─ web.json                     # 小說書架及共用封面、背景索引
│  ├─ 通用/圖片/
│  └─ 小說/
│     └─ 天賦權能/
│        ├─ 架構/web.json          # 小說入口、篇章與圖鑑索引
│        ├─ 劇情/
│        │  └─ 聖地篇/
│        │     ├─ index.json       # 篇章章節列表
│        │     ├─ 001.md
│        │     └─ 002.md
│        ├─ 人物/index.json
│        ├─ 世界觀/index.json
│        └─ 地圖/index.json
└─ 介紹檔/
   ├─ README.md
   ├─ 基本架構.md
   └─ 架構指南.md
```

## 資料載入方向

1. `素材/web.json` 將首頁書架項目連到各小說的架構檔。
2. 小說 `架構/web.json` 指向篇章索引，以及人物、世界觀、地圖索引。
3. 篇章 `index.json` 指向 Markdown 正文；章節完成狀態驅動圖鑑解鎖。
4. 圖鑑索引以穩定 `id` 尋址，讓人物、世界觀與地圖項目可互相連結。

各資料檔以相對路徑連接，方便新增小說或移動整個小說資料夾。

## 程式模組與狀態追蹤

| 模組 | 責任 |
| --- | --- |
| `js/main.js` | 啟動網站、將 HTML 事件連到功能模組、調整瀏覽畫布縮放 |
| `js/app-state.js` | 集中保存目前小說、篇章、圖鑑及閱讀狀態 |
| `js/navigation.js` | 顯示畫面、切換閱讀模式、管理左上角麵包屑 |
| `js/data-store.js` | 載入 JSON、解析相對路徑、讀寫 `localStorage` |
| `js/catalog.js` | 書架、篇章、人物／世界觀／地圖列表、搜尋與資料連結 |
| `js/reader.js` | 載入 Markdown、框架內連續捲動、保存位置及完成章節 |
| `js/reading-presentation.js` | 從首頁起選擇小／中／大全站尺寸並保存偏好 |

`navigation.js` 中的麵包屑項目帶有返回該層畫面的動作；閱讀時路徑為「首頁 → 小說 → 小說章節 → 篇章 → 章節」。返回前層會重建對應列表，不另維護一組「上一頁」按鈕或第二份頁面狀態。

全站尺寸由 `reading-presentation.js` 設定 CSS 變數，僅套用字級、按鈕尺寸、卡片間距和網格欄數；不改變中央面板或閱讀框架尺寸。尺寸控制列固定於實際視窗，因此不會跟隨 16:9 畫布縮小。所有元素使用 `box-sizing: border-box`，padding 不會增加宣告尺寸。閱讀框架固定高度，只有正文區可捲動；操作列不隨長文移動。正文捲動比例保存在 `localStorage`，重新開啟時可回到上次位置。
